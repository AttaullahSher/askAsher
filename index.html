Whatever you pick answers first. If it fails — bad key, rate limit, retired model — it quietly walks down the rest of the list instead of showing you an error.

Models & keys

Keys live in this browser and go straight to the provider. Nothing passes through a server of mine — there isn't one. Use a spend-capped key: anything running script on this page can read it.

Speaking and listening happen in the browser itself — no key, no upload, nothing recorded anywhere. If you have a Groq key you can switch listening to Whisper instead, which handles accents and mixed languages better.

Image studio

Images need no key — they come from Pollinations, which serves open models like Flux. If one model refuses, the next one gets a go.

Add Ask Asher to your Home Screen

iPhone and iPad install from Safari's share menu rather than a button.

  1. Tap Share in the Safari toolbar — the square with the arrow.
  2. Scroll and tap Add to Home Screen.
  3. Tap Add. It opens full screen after that, no address bar.

Your chats and memory carry over — same browser storage.

Offline — Ask Asher still opens, but models can't be reached.
